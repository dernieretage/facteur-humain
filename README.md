# facteur.humain

Creative production based in Paris.

Live site: https://dernieretage.github.io/facteur-humain/

## Stack

Static, dependency-free HTML / CSS / vanilla JavaScript. Hosted on GitHub Pages.

- `index.html` — page skeleton + meta + structured data
- `styles.css` — design system (black canvas, serif accents, motion tokens)
- `script.js` — artists data, embed parser (Vimeo / YouTube / Instagram), grid renderer, modal player, scroll behaviour
- `assets/covers/` — full-bleed director covers (extracted from the official PDF)
- `assets/thumbnails/` — film and photography grid stills
- `assets/photos/` — individual photographs for special layouts

## Local preview

```bash
cd site
python3 -m http.server 8000
# http://localhost:8000
```
